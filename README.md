# 📌 Calculadora de Médias Escolares

## 🎯 Objetivo do Projeto
Sistema desenvolvido para calcular a média de notas de alunos e informar sua situação: **Aprovado**, **Reprovado** ou em **Recuperação**.
Essa solução ajuda professores e escolas a automatizarem o cálculo, evitando erros e ganhando tempo.

## 🛠️ Tecnologias Utilizadas
- `HTML5` → Para estruturar a página e os campos de entrada
- `CSS3` → Para deixar o visual bonito, organizado e responsivo (funciona no celular)
- `JavaScript` → Para toda a lógica de cálculo e validação dos dados

## ✨ Funcionalidades
✅ Entrada de até 4 notas diferentes
✅ Cálculo automático da média final
✅ Verificação da situação do aluno conforme a média
✅ Validação para impedir entrada de notas inválidas (menor que 0 ou maior que 10)
✅ Interface simples e fácil de usar

## 🚀 Como executar o projeto
1. Faça o download dos arquivos ou clone este repositório
2. Abra a pasta do projeto
3. Dê um clique duplo no arquivo `index.html`
4. O sistema abrirá no seu navegador e já estará pronto para uso
